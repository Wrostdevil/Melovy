## ✨ About Melovy

**Melovy** is a high-fidelity web music player and acoustic
visualization experience that combines:

-   🎵 Music playback
-   🎛️ Analog-inspired controls
-   🎙️ Interactive 3D audio hardware
-   🌊 Real-time audio visualization
-   🏛️ Cinematic environmental backdrops
-   🧘 Mood and acoustic discovery
-   🇮🇳 Indian-inspired visual and musical aesthetics
-   🎧 Spotify playlist integration
-   📱 Responsive desktop and mobile experiences

Instead of treating music as something that simply plays in the
background, Melovy is designed around a different idea:

> **Music should be something you can see, feel, and interact with.**

------------------------------------------------------------------------

# 🎯 Product Vision

Most modern music players prioritize lists, playlists, and minimal
interfaces.

Melovy explores the intersection of:

``` text
              MUSIC
                │
        ┌───────┼────────┐
        │       │        │
        ▼       ▼        ▼
      AUDIO   VISUAL   EMOTION
        │       │        │
        ▼       ▼        ▼
      Web     Three.js  Vibe
      Audio   / WebGL   Discovery
        │       │        │
        └───────┼────────┘
                ▼
        IMMERSIVE LISTENING
```

The goal is to create a listening environment that feels closer to
entering a **private vintage listening room** than opening a
conventional music website.

# 🌊 Real-Time Audio Visualization

Melovy uses the browser's **Web Audio API** to analyze audio and feed
data into the visual experience.

### Audio Pipeline

``` text
Audio Source
     │
     ▼
AudioContext
     │
     ▼
Gain Node
     │
     ▼
Analyser Node
     │
     ├──────────────► Frequency Data
     │
     ├──────────────► Waveform Data
     │
     ▼
Audio Output
```

The resulting audio data can drive:

-   Frequency visualizers
-   Waveform animations
-   VU meters
-   Sound-wave effects
-   3D scene reactions
-   Playback-state animations

# 🧘 Acoustic & Vibe Discovery

Melovy experiments with music discovery through more than conventional
genre browsing.

## 🎼 Prahar-Aware Ragas

Indian classical ragas can be organized around different periods of the
day:

``` text
🌅 Morning
    ↓
☀️ Afternoon
    ↓
🌆 Twilight
    ↓
🌙 Night
```

This creates a contextual listening experience based on time,
atmosphere, and musical tradition.

## 🔊 Solfeggio & Acoustic Experiences

Melovy includes experimental acoustic experiences around frequencies
such as:

-   174 Hz
-   432 Hz
-   528 Hz

These are presented as part of the application's artistic and acoustic
exploration, not as medical claims.

# 🚀 Getting Started

## 1. Clone the repository

``` bash
git clone https://github.com/your-username/melovy.git
```

## 2. Navigate into the project

``` bash
cd melovy
```

## 3. Install dependencies

``` bash
npm install
```

## 4. Start the development server

``` bash
npm run dev
```

Open:

``` text
http://127.0.0.1:5173
```

------------------------------------------------------------------------

# 🔐 Environment Variables

If Spotify integration is enabled, create a `.env` file:

``` env
VITE_SPOTIFY_CLIENT_ID=your_spotify_client_id
VITE_SPOTIFY_REDIRECT_URI=http://127.0.0.1:5173/callback
```

### ⚠️ Security

Never expose a Spotify Client Secret in frontend code.

Never commit:

``` text
.env
.env.local
```

to Git.
